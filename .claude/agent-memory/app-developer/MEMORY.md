# app-developer memory

Lessons from earlier apps, one line each. Newest at the bottom.

- Test SQLite repositories in Jest by mocking expo-sqlite with an adapter over Node 22's built-in node:sqlite (in-memory); run the same contract suite against the memory repository. (moneyplanner, 2026-11)
- In cloud sessions, prefix Expo CLI commands with EXPO_OFFLINE=1: Expo's servers are blocked. (moneyplanner, 2026-11)
- RN 0.88 supports boxShadow strings on all platforms; SVG gradient ids need useId() sanitised (no colons) for web. (moneyplanner, 2026-11)
- Jest picks up every file in __tests__ as a suite: keep fixtures/fakes in a sibling folder (e.g. testing/). Mock a parallel-built engine with a small fake so screen tests don't depend on it. (moneyplanner, 2026-11)
- Never unmount a navigator while data reloads (e.g. swapping the tab bar for a spinner when a query reloads after a save): it resets the tabs to the first one. Show a spinner only when there is no data yet. (moneyplanner, 2026-11)
- expo-router usePreventRemove: turning the guard off is applied on a later render, so going back right after setState is still blocked (iPhone modals stay open). Switch the guard off when the save STARTS, go back after the write + two frames, and never "repeat" an intended exit (on Android it went back twice and closed the app). (moneyplanner, 2026-11)
- iPhone number pads have no Return key: give each numeric field its own InputAccessoryView "Done" bar (one global bar at the root doesn't show over modal screens); also set keyboardDismissMode="on-drag" on scroll views. (moneyplanner, 2026-11)
- Don't open RN Modal pop-ups (pickers, sheets) over iOS modal-presented screens for form fields: they may not close. Use inline option lists (compact grid for long lists of short choices like days). A lock/privacy screen must not render the app underneath (Modals and native modals draw above overlays). (moneyplanner, 2026-11)
- expo-file-system SDK 58 new API: Directory.create({intermediates, idempotent}), File.move(dest,{overwrite}) for atomic temp-then-move writes, textSync exists; fake it in Jest with a Map-backed File/Directory mock. Skip auto-backups of un-onboarded profiles so empty copies don't rotate out real ones. (moneyplanner, 2026-11)
- Reports engine: balance at any date = startingBalance +/- flows (same flows as forecast); compare a 'so far' period with the same elapsed part of the earlier one. Free users: never run buildReport on own data. (moneyplanner, 2026-11)
- Home 'Coming up' shows one row per item (next payment), so after Paid the same title reappears with the next date; tests and walkthrough must compare keys/dates, not titles. (moneyplanner, 2026-11)
- Walkthrough taps by substring text ('Rent') can hit new always-on cards (Cheques card text mentions rent): tap exact. Never run git stash mid-task to compare baselines. (moneyplanner, 2026-11)
- New optional field on a shared type (Category.monthlyLimit): make it optional in the type and normalise to null in repos/backup, or every parallel dev's fixtures break tsc. Walkthrough static server (e2e-web/lib.mjs) sometimes crashes with ERR_HTTP_HEADERS_SENT: rerun. (moneyplanner, 2026-11)
- jest-expo treats every .ts/.js under __tests__/ as a test: keep fixtures as plain .txt/.csv files (read via a loader outside __tests__); no @types/node, so declare require/__dirname locally. (moneyplanner, 2026-11)
- Arabic: normalise (ئ->ي, ة->ه, أإآ->ا) BOTH text and keyword/header literals, or regexes with دائن never match. xlsx: build fixtures in tests with fflate zipSync, no binaries. (moneyplanner, 2026-11)
- Store graphics: render-graphic.mjs flattens transparency (white); use a small Playwright script with omitBackground:true for adaptive-icon foreground/monochrome PNGs. check-listing bans the words 'coming soon'/'placeholder' in listing text. (moneyplanner, 2026-11)
- expo-sharing `useIncomingShare()` throws on web (getSharedPayloads unsupported): mount the receiver only when Platform.OS !== 'web', inside an error boundary; `clearSharedPayloads` deletes shared file copies, so clear text shares at once but files only after reading. Tests: mock '@/import/ocr/native' and '@/import/pdf/native' (`{ocrNative:{}}`) or importing '@/import/read' fails with "Cannot find native module". react-hooks/set-state-in-effect flags calling a state-setting fn in an effect: defer with Promise.resolve().then. (moneyplanner, 2026-11)
- New native modules can break only the RELEASE build at R8 ("Missing class …", e.g. pdfbox's optional com.gemalto.jp2): unit tests and the web walkthrough can't catch it. Read the R8 error, add a -dontwarn/keep rule via the app's plugins/with-proguard-rules.js, and check it with a local `expo prebuild`. (moneyplanner, 2026-11)
- Scrubbable SVG chart: use RN responder props (grant/move/release) with pageX minus (pageX-locationX) at grant, pointerEvents none on Svg, touchAction none on web; keep scrub state inside a small hero component so the screen doesn't re-render. RNTL render/fireEvent are async here (await them); never run 'cat > file' without a heredoc. (moneyplanner, 2026-11)
- Balance history: anchor snapshots + cumulative recorded flows (balance(d)=anchor+cum(d)-cum(anchor)) handles forward and backward in one pass. Removing an enum value (chart style) needs a normaliser (chartStyleOf) at every read path: repos, backup, screens. Walkthrough with HIST_SHOT_DIR saves chart shots. (moneyplanner, 2026-11)
- Foundation refactors: capture walkthrough chart screenshots (HIST_SHOT_DIR/CHART_SHOT_DIR) before and after and cmp them (byte-identical = safe); in schema merges never use ?? for values where null is real (payday); the WeakMap-per-plan-input memo shares engine results between screens. (moneyplanner, 2026-11)
- Edit-in-place sheets: never open a Sheet (RN Modal) from inside a Sheet (explainers, PIN pads): render the second step in place of the first inside the same Sheet, or use a pushed screen. Save-on-blur needs TextField onBlur; a field unmounting with a typed value should flush its save; in web walkthroughs close a sheet by clicking the backdrop at (8,8) and commit a field with Tab. Restore order matters when saving dependent fields one by one (caution < high). (moneyplanner, 2026-11)
- Web walkthrough: RN Modal sheets ignore a backdrop click while they slide in (wait ~600ms before mouse.click(8,8)); RN-web radio chips expose no aria-checked (compare background colour); a full-screen "Close" Pressable can't be clicked at its centre (the sheet covers it). In python edits of e2e files never slice with str.index of a string that also occurs earlier: it duplicated half the file. (moneyplanner, 2026-11)
- A new settings key with a registry-validated list (Home layout) needs a full normalised sample in the repository contract's SETTING_SAMPLES, or the toEqual round-trip fails (missing ids get appended). Keep the id list in a pure module the schema can import (no React). (moneyplanner, 2026-11)
- Test at 320×640 too (the CI emulator's size): three tiles with minWidth 96 ran off the edge; Coming up rows (name + amount + bell + Paid) squashed names to "S."; a 'grid only if every label is short' rule broke on one long label. Fixes: minWidth 0, amount under the name when width < 380, never numberOfLines on money, full-width rows for odd items. Local `walkthrough --small` caught all of it in minutes; the device run had wasted 40 min each. Look at the screenshots, not just the PASS lines. (moneyplanner, 2026-11)
